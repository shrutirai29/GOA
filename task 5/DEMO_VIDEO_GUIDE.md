## 🛠️ Recommended Recording Setup

### 1. Screen Recorder Software
- **Loom** (Easiest — web cam bubble + screen + instant link)
- **OBS Studio** (High-quality, free, configurable audio tracks)
- **Screen Studio / CleanShot X** (Smooth cursor zooming and polished visuals)
- **Windows Game Bar** (`Win + Alt + R` built into Windows)

### 2. Resolution & Audio
- **Resolution:** 1080p (1920x1080) at 30fps or 60fps.
- **Audio:** Ensure your microphone input is crisp and not clipping. Wispr Flow will listen to your microphone while your recording software captures the same microphone.

### 3. Screen Layout
- Arrange your browser window occupying 80-90% of your screen.
- Ensure the **Wispr Flow floating widget / indicator pill** is clearly visible on screen so evaluators see Wispr Flow activating and transcribing in real time.

## 🚀 Uploading Your Video

1. **YouTube (Recommended):**
   - Upload as **Unlisted** (or Public).
   - In description, paste:
     - GitHub Repository link
     - Live App link (if hosted on Vercel/GitHub Pages or local instructions)
     - Referral Link: `https://ref.wisprflow.ai/hhg`
2. **Loom:**
   - Ensure permissions are set to *"Anyone with the link can view"*.
3. **Google Drive:**
   - Set link sharing to **"Anyone on the internet with the link can view"** (avoid access request blocks).
